# Newton 1.5.0 Submodule Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Point `newton/` at tagged Newton 1.5.0 while keeping the fork gather-wrench API and the `usd-core>=26.5,<27` pin, and migrate apple-pick call sites that 1.5.0 deletes.

**Architecture:** Merge `v1.5.0` on `abhinavj98/newton`, replay the two wrench commits against 1.5.0's `evaluate_joint_force_hessian` (new cable-rest arrays), re-apply the usd-core pin, then bump the parent submodule SHA and migrate `ModelFlags` / `joint_target_q`. Do not pin raw `upstream/main`.

**Tech Stack:** git submodule (`newton/` → `git@github.com:abhinavj98/newton.git`), `uv`, pytest, Newton unittest, Warp.

**Spec:** `docs/superpowers/specs/2026-08-27-newton-1.5-submodule-update-design.md`

## Global Constraints

- Execute in a **sibling worktree**, not on `main`. This checkout is already `feature/real-replay-parallel-sysid`; create `../apple_pick_sim-newton-1.5` from this branch (or continue here only if the user explicitly says so).
- Do **not** `git submodule update` to stock `v1.5.0`. That drops `gather_joint_wrench_child_com` and reverts usd-core to `<26.5`.
- Overlay must include: wrench kernel + public method + Newton gather unittest + `usd-core>=26.5,<27`.
- TDD for apple-pick migrations: failing test before production edit.
- Do not retune VBD `kd` / Young's search boxes in this slice.
- Do not claim SIGSEGV fixed without a crash-*rate* comparison (`docs/in-process-rebuild-heap-corruption.md`).
- `uv run --env-file pytest.env python -m pytest -p no:launch_testing …`
- Newton tests use unittest: `uv run --directory newton --extra dev python -m newton.tests -k test_gather_joint_wrench`
